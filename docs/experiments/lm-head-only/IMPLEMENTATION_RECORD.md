# 当前实现

来源：工作区主设计第 14.23 节。正式入口固定 micro=16，支持 G/T/K 的 smoke、八候选 clean/grid、暂停恢复和结果汇总。完整 Head 更新、冻结 backbone、优化器和噪声公式保持原实现。

已移除硬件选档、旧输入测速和经验 K 的专用代码。Python CLI、训练入口、根目录登记和曲率入口统一校验正式 micro；显式合成 CPU 测试允许小批量以验证分块与恢复。

H100 操作统一见仓库 LM_HEAD_RUN.md，发布版本 lm-head-h100-m16-20261115-v3。旧部署使用原代码继续运行；新代码使用新的输出根并重新 smoke。正式 K 仍需拟合与独立留出验收，且绑定代码/输入身份。

H100 默认启用 SwanLab，项目 nanogpt-lm-head；Key 由任务环境提供。LM Head 适配器复用独立上传进程，补充目标评估与异常状态；原 last-k 上传模块保持不变。恢复记录关联同一候选身份与实际恢复步，上传失败保留本地训练。启动检查只核对配置与 SDK，实际云端送达由 H100 smoke 页面验收。

历史记录位于 history/，不参与当前命令或默认配置。
