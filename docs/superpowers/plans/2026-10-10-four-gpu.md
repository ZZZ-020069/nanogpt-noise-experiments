# Four-GPU Launcher Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver a single-node four-GPU Bash entry point, test it, and push the verified code to the user's repository.

**Architecture:** Keep the v1.4 scientific protocol unchanged. The Bash wrapper dispatches preflight checks and four-worker torchrun to the existing candidate/node controllers. Smoke and formal output directories remain separate; no automatic full-grid submission.

**Tech Stack:** Bash, Python, PyTorch DDP/NCCL, unittest, Linux CPU/Gloo CI.

Execution is inline because the user requested implementation; the named execution sub-skills are not installed. This is an implementation checklist, not a second experiment design.
